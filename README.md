# 🧮 Harshvardhan Calculator

A modern, professional, and responsive **Scientific Calculator Web Application** built using **HTML, CSS, and JavaScript**.

The calculator is designed to provide a clean desktop-style experience with scientific operations, calculation history, keyboard support, and light/dark themes.

---

## 📌 Project Overview

**Harshvardhan Calculator** is a browser-based calculator application designed with a professional user interface.

It supports basic arithmetic operations as well as several scientific functions. The application is optimized to use the full laptop/browser screen and provides a separate calculation history panel.

The project was created to practice and demonstrate frontend web development concepts such as:

- HTML structure
- CSS layouts and responsive design
- JavaScript DOM manipulation
- Event handling
- Mathematical expression evaluation
- Keyboard interaction
- Theme switching
- Dynamic history management

---

## ✨ Features

### 🔢 Basic Calculations

Supports all common arithmetic operations:

- Addition `+`
- Subtraction `−`
- Multiplication `×`
- Division `÷`
- Decimal numbers
- Double zero `00`
- Percentage `%`
- Positive/Negative `±`

---

### 🧪 Scientific Functions

The calculator also includes:

- `sin()` — Sine
- `cos()` — Cosine
- `tan()` — Tangent
- `log()` — Base-10 logarithm
- `ln()` — Natural logarithm
- `√` — Square root
- `π` — Pi
- `e` — Euler's number
- `x²` — Square
- `xʸ` — Power
- Parentheses `( )`

> Trigonometric functions use degrees.

---

## 🕘 Calculation History

The application includes a dedicated **Calculation History** panel.

It allows users to:

- View previous calculations
- View calculation results
- Click a previous result to reuse it
- Store up to 15 recent calculations
- Clear all calculation history

---

## ⌨️ Keyboard Support

The calculator can also be controlled using the keyboard.

| Keyboard Key | Function |
|---|---|
| `0-9` | Enter numbers |
| `.` | Decimal |
| `+` | Addition |
| `-` | Subtraction |
| `*` | Multiplication |
| `/` | Division |
| `^` | Power |
| `Enter` | Calculate |
| `=` | Calculate |
| `Backspace` | Delete |
| `Esc` | Clear |
| `( )` | Parentheses |

---

## 🌙 Theme Support

The calculator provides a theme-switching option.

### Dark Mode
- Modern dark interface
- Comfortable for low-light environments
- Professional desktop appearance

### Light Mode
- Bright and clean interface
- Easy to read in daylight

Click the theme button in the top-right corner to switch between modes.
